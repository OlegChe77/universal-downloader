How it works

What happens inside the program and what to do if it stops downloading.

Updates

The first thing to try if downloads stop working.
The program checks by itself every three days and offers the update on the main page.

How to use

StartingThe desktop shortcut “Универсальный скачиватель” (Universal Downloader). While the program starts, a “Starting…” splash is shown at the bottom right — it disappears when the page opens. There is no black window: the program lives as an arrow icon by the clock (bottom right; if you do not see it, click the “^” arrow next to the clock). Clicking the icon opens the page, right-click opens the menu: “Open”, “Downloads folder”, “Exit”.
First startThe program installs what it needs (Python, yt-dlp, ffmpeg, Deno) by itself — a couple of minutes, without windows: an icon with the hint “Installing components” appears by the clock, then the page opens. The same happens when the program needs new components. If the installation fails, a window with the error appears. Запуск.bat (Start) in the program folder shows the installation progress in a window.
PageThree tabs: “By link”, “Music” and “Proxy” (for blocked sites). The download folder (the “Choose folder” button, the “ask for the folder every time” checkbox) is right under the link or search field on both tabs. Download progress with “Cancel” and “Show” buttons appears where you started it: for a video — in its card under the title, for a song — in its row in the results, for a list of links — in the list card. There is no separate list of downloads: the files are in the folder (“Open” next to the folder). The theme button in the corner switches: as in Windows → light → dark. The language button switches Russian ↔ English.
By linkPaste the address of a video, playlist or page — the options appear by themselves. Choose the video quality (MP4) or “Audio only” (MP3/M4A). If you type a song name instead of a link, the program switches to “Music” by itself.
MusicType the artist and title — a list of 10 results appears: the search runs on YouTube, SoundCloud and Rutube at once, the site is shown in the song row. If a site did not open (for example, YouTube is blocked), the program says which one above the list, and songs from the others still appear. Paid SoundCloud tracks (30-second previews) are not listed. MP3 downloads the song right away (with cover and tags), “More formats” gives video or M4A. “Show 10 more” adds new results without repeats. The song row shows the download: percent, “Cancel”, and “Show” when it is done. Use the checkboxes to select several songs and download them with one button (MP3 or M4A) — one at a time.
ListenThe ▶ button on a song cover on the “Music” tab plays the audio right on the page, without downloading anything. A player appears at the bottom: pause, seek, time, volume and the “Close” cross. One song plays at a time: starting another stops the first one. When a song from the results ends, the next one starts; ⏮ ⏭ in the player are previous and next (⏮ after 3 seconds returns to the start of the song). The MP3 button in the player downloads what is playing now. Keys: Space — pause, ← → — 5 seconds back and forward (when the cursor is not in a text field); keyboard media keys work too. The audio starts in 2–5 seconds — the program finds it through yt-dlp. Sites that serve audio in small chunks (SoundCloud, Rutube and others) are first downloaded to a temporary folder — the audio starts a bit later, in 5–15 seconds. Live streams, playlists and such recordings longer than 40 minutes cannot be played — only downloaded.
Several linksOn the “By link” tab, paste links in a column (one per line; Shift+Enter adds a line by hand). A list appears — choose one option for all, for example “MP3” or “up to 1080p”. The files download one at a time. Lines without a link and duplicates are skipped.
Audio trackIf a video has several dubs (YouTube dubbing, movies), the card shows “Audio track”. Russian is selected first, otherwise the original. The choice applies both to video and to MP3/M4A. “All tracks at once” puts all languages into one video: switch them in the player (VLC, Movies & TV — the audio menu); the file gets bigger. Playlists and link lists take the Russian track if there is one.
SubtitlesIf a video has subtitles, the card shows “Subtitles”: the language and how to save them — embed in MP4 (turn them on in the player’s subtitle menu) or a separate .srt file next to the video (the player picks it up by itself). The program remembers the chosen way. “No subtitles” is selected by default — choose a language if you need them. For YouTube there are also auto-generated subtitles and an auto-translation into Russian (made by the site, may contain mistakes). Subtitles are for video only: MP3/M4A, playlists and link lists get none. If the site did not give the subtitles, the video still downloads — the download row says “no subtitles”.
COUBOn COUB the picture is a loop of a few seconds, and the audio is a whole song. As on the site, the video is looped while the audio plays (without re-encoding, so the file is bigger). In the card you can choose “play once” — then the audio is cut to the video length. MP3/M4A — the whole song.
Movies and seriesOnline cinema sites (kinogo and similar) show movies in the CCDN, ShizaHD and VeoVeo players. Paste a link to a movie page — the card shows a “What to download” row: the player (if the first one does not open, the program takes the next one), and for a series — the season and episode. “All episodes” downloads the whole season one by one, “All seasons” — the whole series. Dubs are in “Audio track”. The Alloha player is not supported yet.
Compress videoA downloaded video (in its card) has a “Compress” button: a file “… (сжато).mp4” appears next to it (H.265 format), the original stays — delete it yourself if the compressed one is fine. Videos from YouTube and other sites are already compressed, so they shrink by about 20–50%; videos shot on a phone — several times. If it barely got smaller, the second file is not kept. Compression loads the processor and takes about as long as the video lasts (longer on a slow computer); several videos are compressed one at a time, “Cancel” stops it. Compressed videos play in browsers, VLC, phones and TVs; the standard Windows 10 player may need “HEVC Video Extensions” from the Microsoft Store.

No need to copy the address by hand: click a button on a page with a video — the program opens with the link already pasted and checked. If the program page is already open, the browser tries to send the link there instead of a new tab (the extension always does, the bookmark button — when the browser allows it). Bookmark button

⬇ Send to Downloader ← drag it with the mouse to the bookmarks bar
  1. Show the bookmarks bar: Ctrl+Shift+B (in Safari — ⌘+Shift+B; in Opera — the “Easy setup” icon at the top right → “Show bookmarks bar”).
  2. Hold the blue button with the mouse and drag it to the bar, as in the picture. No need to click it here.
  3. Open a video or song on any site and click the “Send to Downloader” bookmark.

Cannot drag it (for example, the bar is hidden in Yandex)? , create any bookmark (Ctrl+D), open “Edit” and paste the code into the “URL” field. If the browser blocked the pop-up, the program opens in the same tab — the “Back” button returns you to the site.

Extension

Adds a button with the program icon to the browser toolbar and the “Send to Downloader” item to the right-click menu: on a page it sends the page address, on a link — the link itself. If the program is not running, the button starts it: the browser asks whether to open the “Универсальный скачиватель” (Universal Downloader) app — click “Open”, and the “Always allow” checkbox removes this question. If your extension was downloaded before this version, download and install it again.

Download the extension (zip) — one archive for all browsers, the program port is already in it.

No extension store needed: browsers allow installing an extension from a file. The extension sends nothing to the internet — it only opens the program page on your computer (http://127.0.0.1) and passes it the page or link address.

Chrome, Edge, Yandex Browser, Opera

  1. Click “Download the extension (zip)” above. The file downloader-extension.zip appears in your “Downloads” folder.
  2. Right-click it → “Extract All…” → “Extract”. You get a folder with manifest.json directly inside (if there is another folder inside, you need the one that contains manifest.json).
  3. Move this folder to where it will stay for good, for example into the program folder next to app.py. The browser does not copy the extension, it loads it from this folder: delete or rename the folder and the extension stops working.
  4. Open the extensions page — type it into the address bar and press Enter:
    • Chrome — chrome://extensions
    • Edge — edge://extensions
    • Yandex — browser://extensions
    • Opera and Opera GX — opera://extensions
  5. Turn on “Developer mode”: in Chrome, Yandex and Opera — the switch at the top right, in Edge — in the left panel (if you do not see it — the ☰ button at the top left).
  6. A row of buttons appears. Click “Load unpacked” and choose the folder from step 3 — the one with manifest.json, then “Select Folder”.
  7. The list shows “Universal Downloader” with the switch on. If there is a red “Errors” button next to it, most likely the wrong folder was chosen: remove the extension and choose the folder with manifest.json.
  8. Pin the button to the toolbar: the puzzle icon to the right of the address bar → the pin next to “Universal Downloader” (in Edge — the eye icon “Show in toolbar”, in Opera — the cube icon to the right of the address bar → the pin).
Chrome and Edge sometimes offer to disable developer mode extensions at startup — close that message with the cross. Developer mode is safe: it only allows installing extensions from a folder.

Firefox

Firefox permanently installs only extensions signed by Mozilla, and this extension is built on your computer and has no signature. So in regular Firefox it is installed temporarily — until the browser closes. It takes half a minute, no need to unpack the archive.

  1. Click “Download the extension (zip)” above and remember where downloader-extension.zip is.
  2. Type about:debugging#/runtime/this-firefox into the address bar and press Enter (or about:debugging → “This Firefox” on the left).
  3. Click “Load Temporary Add-on…” and choose the file downloader-extension.zip itself (manifest.json from the unpacked folder works too).
  4. The “Temporary Extensions” section shows “Universal Downloader” with the line “Background Script: Running”. There should be no warnings or errors.
  5. Pin the button: the puzzle icon on the toolbar → the gear next to “Universal Downloader” → “Pin to Toolbar”.

After Firefox restarts, the extension is gone — repeat steps 2–3, no need to download the archive again. If that is inconvenient, use the bookmark button above in Firefox: it stays for good and does the same, except for the right-click menu item.

Install permanently in Firefox (Developer Edition, Nightly or ESR)

Regular Firefox does not allow unsigned extensions. In Firefox Developer Edition, Nightly and ESR you can allow them:

  1. Open about:config, accept the warning, find xpinstall.signatures.required and set it to false (double-click).
  2. Rename downloader-extension.zip to downloader-extension.xpi.
  3. Open about:addons → the gear → “Install Add-on From File…” → choose the .xpi → “Add”.

How to use

  • Toolbar button — open a video or song and click the program icon: the program opens with this link.
  • Right-click on a page or on an embedded video → “Send to Downloader” — the same.
  • Right-click on a link → “Send to Downloader (this link)” — sends the link without opening it: handy in a video list, search results or a feed.
  • If the program tab is already open, the link goes there (the player is not interrupted), otherwise a new tab opens next to it.

Update, remove, if it does not work

  • Changed the program port (port in settings.json)? Download the archive again. Chrome, Edge, Yandex, Opera: replace the files in the extension folder and click the round “Reload” arrow of the extension on the extensions page. Firefox: on about:debugging — “Remove”, then load the new archive.
  • To remove — the “Remove” button on the extensions page; after that you can delete the folder too.
  • “This site can’t be reached” opens — the program is not running: start it with the desktop shortcut and click the button again.
  • In Firefox a new tab opens every time even though the program is already open — allow the extension access to 127.0.0.1: about:addons → “Universal Downloader” → “Permissions”.

If it stopped working

Find your case. The error text is shown on the page next to the download, and startup errors are in the program.log file in the program folder. “Restart the program” below means: right-click the icon by the clock → “Exit”, then the desktop shortcut again.

YouTube (or another site) stopped downloading, although it worked before

Almost always the site changed its protection and a fresh yt-dlp version is needed.

  1. Click “Update yt-dlp” at the top of this page.
  2. Restart the program (the icon by the clock → “Exit”, then the shortcut).
  3. Try again.

If it still does not work after the update, the fix is not out yet. It usually comes out within 1–3 days. You can check whether the problem is known in the yt-dlp issue list: search by the site name.

“The site requires signing in” / “Sign in to confirm you're not a bot”

The site wants to see that you are signed in. Give the program the cookies from your browser:

  1. Install the Get cookies.txt LOCALLY extension in Chrome or Edge (in Firefox — cookies.txt).
  2. Open the site (for example, youtube.com) and make sure you are signed in.
  3. Click the extension icon → Export.
  4. Rename the file to cookies.txt and put it into the program folder, next to Запуск.bat.
  5. Try again — no restart needed.
cookies.txt gives access to your account. Never send it to anyone. Cookies expire over time — if the error comes back, export them again.
YouTube shows few qualities or mentions JavaScript / “n challenge”

YouTube needs a JS engine (Deno), which the program installs by itself.

  1. Click “Exit” in the icon menu by the clock and run Запуск.bat — it installs Deno by itself (internet required).
  2. If that does not help, do a clean reinstall (see below).
  3. Still no luck — update yt-dlp with the button at the top.
The page does not open
  • The program runs while its icon is by the clock. No icon — start the desktop shortcut.
  • The page address: http://127.0.0.1:8765. You can change the port in settings.json (the line "port": 8765, then restart the program) — for example, if 8765 is used by another program. After changing the port, drag the bookmark button again and reinstall the extension.
  • The icon does not appear — run Запуск.bat: it shows in a window what goes wrong, and errors of the program itself are in program.log. If Python or the components could not be downloaded, check the internet (python.org and pypi.org must open) and run it again.
  • An antivirus may block ffmpeg.exe or the script itself — add the program folder to its exclusions.
Errors at startup, “ModuleNotFoundError”, everything broke after an update

Reinstall the program cleanly — your files in Скачанное (Downloads) are safe:

  1. Close the program: the icon by the clock → “Exit”.
  2. Delete the python and bin folders in the program folder.
  3. Run Запуск.bat — it installs everything again (internet required, about a minute).
Downloaded, but there is no sound, the video does not open or an “ffmpeg” error
  • Delete the bin folder and restart the program — ffmpeg will be put back.
  • 1440p and 4K videos from YouTube use the VP9/AV1 codecs, not every player opens them. Install VLC or download in 1080p.
“This site is not supported” / “The video is DRM-protected”
  • Make sure the link leads to the page of the video itself, not to the home page or a feed.
  • Is the site in the list of supported sites? If not, the program tries to find a video on the page by itself, but that does not always work.
  • Netflix, Disney+, Amazon Prime Video, Spotify, Apple Music and similar are DRM-protected — they cannot be downloaded.
“Listen” does not play or shows an error
  • Wait a few seconds: while the program looks for the audio, a wheel spins on the button.
  • The error is shown in the player under the title. From SoundCloud, Rutube and similar sites the audio starts later (the program downloads the song first), and recordings longer than 40 minutes from them cannot be played — only downloaded.
  • Click ▶ in the player again — the program looks for the audio again. Did not help — update yt-dlp with the button at the top.
  • No sound, but the time runs — check the volume in the player (the speaker icon) and in Windows.
Downloads are very slow

The speed is set by the site itself. Some sites (VK, Rutube) serve video in small chunks — that is slower than YouTube. Choosing a lower quality helps. If it has become slow only now — update yt-dlp.

If you use a VPN

  • A VPN for the whole computer (a separate app) — the program goes online through it, just like the browser.
  • A VPN browser extension does not affect the program: it changes only the browser itself, while the program goes online on its own. What to do:
    • install a VPN app on the computer — many VPN services have a Windows app in addition to the extension;
    • if the VPN app works as a proxy (v2rayN, Hiddify, NekoBox, Clash, Happ and similar), you do not need to turn it on “for the whole computer”: when a site does not open directly, the program finds the proxy by itself and goes through it. To find it by hand — on the main page: the “Proxy” tab → “Find”;
    • not found — enter the proxy address from the VPN app settings (the “Proxy”, “SOCKS” or “Port” section), for example socks5://127.0.0.1:10808 or http://127.0.0.1:10809.
    YouTube and sites that did not open directly go through the proxy (or all sites — the “all sites through the proxy” checkbox). Other sites still download directly. When you turn the VPN app off, the program goes back to connecting directly by itself.
  • A VPN only for selected apps (split tunneling) — add python\python.exe from the program folder to the list.
  • YouTube through a VPN asks to “confirm you are not a bot” more often. Switch servers or add cookies.txt.
  • Local sites and online cinemas may not give the video through a VPN in another country — turn the VPN off for them.
Do not turn on or switch a VPN during a download or while listening: video links are tied to your address, and the download breaks with error 403. Then just start it again.

Secure DNS

To open a site, the computer first asks the provider’s DNS for its address. A provider may “not know” the addresses of blocked sites — then the download stops with the error “Could not find the site” (getaddrinfo failed), although the internet works.

The “Secure DNS” checkbox on the “Proxy” tab (off by default): if the provider’s DNS did not find the address, the program asks Cloudflare or Google over HTTPS — the provider does not see this request and cannot replace it. Other sites are looked up as usual.

  • This is not a VPN: if the provider blocks the connection to the site itself, you need a VPN or a tool like zapret — with them Secure DNS helps.
  • It affects only this program, Windows settings do not change.

Manual commands

If the buttons do not help. Open PowerShell in the program folder (in File Explorer: Shift + right-click on an empty spot → “Open PowerShell window here”).

Update yt-dlp:

python\python.exe -m pip install -U "yt-dlp[default,curl-cffi]"

See what yt-dlp finds at a link, and the full error text:

python\python.exe -m yt_dlp -F "link"

Check the yt-dlp version:

python\python.exe -m yt_dlp --version

How to uninstall the program

Run Удалить.bat (Uninstall) in the program folder. It shows what will be removed and asks for confirmation. Then it:

  1. closes the program (the icon by the clock disappears, unfinished downloads stop);
  2. if the Скачанное (Downloads) folder inside the program has files — asks whether to delete them or move them to the desktop;
  3. removes the desktop shortcut and the udl-downloader: link the extension uses to start the program;
  4. deletes the whole program folder — with the settings, cookies.txt, its own Python and ffmpeg.

Files downloaded to another folder (chosen with the “Choose folder” button) stay in place. The program installs nothing into Windows, so it is not in “Apps” and there is nothing else to clean up.

The extension and the bookmarklet live in the browser — remove them yourself: the “Universal Downloader” extension — on the extensions page (chrome://extensions, edge://extensions, browser://extensions, opera://extensions; in Firefox it disappears after a restart anyway), the bookmark button — right-click → “Delete”.

By hand: right-click the icon by the clock → “Exit”, then delete the program folder and the “Универсальный скачиватель” shortcut on the desktop. The udl-downloader: link can stay — without the program it does nothing.
